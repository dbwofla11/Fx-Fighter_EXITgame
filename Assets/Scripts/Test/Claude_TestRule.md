# Claude Test Rules

## 목적

기존 기능을 검증하기 위한 테스트만 수행한다.

---

## 규칙

- 기존 아키텍처를 변경하지 않는다.
- 기존 클래스 및 코드를 수정하지 않는다.
- 리팩토링하지 않는다.
- 새로운 기능을 추가하지 않는다.
- 필요한 경우 테스트 코드만 작성한다.
- 테스트 코드는 반드시 `Test` 폴더에만 생성한다.
- 테스트를 위해 기존 코드에 의존성을 추가하거나 구조를 변경하지 않는다.

---

## 테스트 대상

다음 기능이 정상 동작하는지만 확인한다.

- Skill 적용
- Job 적용
- Stat 계산
- 확률 계산
- 가격 계산
- NextTurn 실행 순서

---

## 수정 허용 범위

허용

- Test 폴더 내 테스트 코드 작성
- 테스트 실행에 필요한 Mock 데이터 작성

금지

- 기존 Runtime 코드 수정
- 클래스 구조 변경
- 함수 시그니처 변경
- 변수명 변경
- 폴더 구조 변경

---

## 결과

각 테스트는

- PASS
- FAIL

로 출력한다.

FAIL인 경우에는

- 원인
- 재현 방법

만 작성한다.
