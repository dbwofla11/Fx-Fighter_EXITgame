# Claude Review Rules

## 목적

코드를 실행하지 않고 함수 호출 관계와 로직을 검토하여 논리적인 문제만 확인한다.

---

## 규칙

- 기존 Runtime 코드를 수정하지 않는다.
- 기존 아키텍처를 변경하지 않는다.
- 리팩토링하지 않는다.
- 새로운 기능을 추가하지 않는다.
- 코드 실행이나 테스트 코드를 작성하지 않는다.
- 함수 호출 흐름과 계산 로직만 검토한다.

---

## 검토 대상

- Skill 적용
- Job 적용
- Stat 계산
- 확률 계산
- 가격 계산
- NextTurn 호출 순서

---

## 확인 사항

다음과 같은 논리적 문제가 있는지만 확인한다.

- NullReference 가능성
- 함수 호출 순서 오류
- 계산식 오류
- 잘못된 값 전달
- 누락된 처리
- 논리적으로 도달할 수 없는 코드

---

## 금지 사항

- 클래스 구조 변경
- 함수 시그니처 변경
- 변수명 변경
- 새로운 설계 제안
- 코드 스타일 수정
- 성능 최적화

---

## 결과

각 검토 항목을

- PASS
- FAIL

로 작성한다.

FAIL인 경우에는

- 문제 원인
- 문제가 발생하는 코드 위치
- 최소 수정 방안

만 작성한다.
