# Claude Guardrail

## 목표

기존 아키텍처를 유지한 상태에서 현재 작업만 구현한다.

---

## 변경 금지

- 폴더 구조 변경 금지
- 기존 클래스 삭제 금지
- DI / ECS / GameContext 도입 금지
- 불필요한 리팩토링 금지

---

## 구현 원칙

- 기존 구조를 최대한 활용한다.
- 필요한 경우에만 새 클래스를 추가한다.
- 작업 범위를 벗어난 수정은 하지 않는다.

---

## 코드 스타일

- 단순하고 읽기 쉽게 작성한다.
- Unity 기본 스타일을 따른다.
- Static Calculator와 Singleton Manager 구조를 유지한다.
