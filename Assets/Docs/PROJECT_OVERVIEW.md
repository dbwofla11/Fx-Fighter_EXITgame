# 프로젝트 개요

## 프로젝트 소개

본 프로젝트는 Unity 기반의 턴제 코인 투자 시뮬레이션 게임이다.

플레이어는 직업과 스킬을 활용하여 시장에 영향을 주고, 코인을 거래하여 자산을 늘리는 것이 목표이다.

---

# 게임 진행

1턴 = 1일

하루가 지나면 시장이 다시 계산되며 새로운 가격이 결정된다.

플레이어는 매 턴 다음 행동을 수행할 수 있다.

- 직업 선택
- 스킬 활성화 / 비활성화
- 코인 매수(Long)
- 코인 매도(Short)

각 행동은 시장 상태에 영향을 주며 다음 턴 가격 변화에 반영된다.

---

# 시장 시스템

시장은 여러 스탯을 기반으로 계산된다.

- 코인 지지도(Support)
- 코인 상승률(Growth)
- 의심도(Doubt)
- 거래량(Volume)
- 발행량(Supply)
- 이벤트 확률
- 현재 가격

각 스탯의 정의와 계산 공식은 아래 문서를 따른다.

> Docs/GAME_FORMULA.md

---

# 이벤트

게임에는 다양한 이벤트가 존재한다.

- 플레이어 거래
- 직업 효과
- 스킬 효과
- 시사 이벤트

이벤트는 시장 스탯에 영향을 주며 최종 가격 계산에 반영된다.

---

# 목표

플레이어는 시장을 분석하고 적절한 시점에 투자하여 자산을 극대화하고 최종적으로 EXIT 조건을 달성하는 것이 목표이다.
