# 이슈: 코인설계 스킬 정리 및 카테고리 라벨 배치

## 목적

코인설계 스킬 트리에서 사용하지 않는 스킬을 제거하고, 아이콘 위의 카테고리 라벨과 배치를 현재 기획에 맞춘다.

## 변경 사항

- `스테이킹`, `감사보고서`, `거버넌스시스템`을 스킬 에셋·씬 DB·UI 아이콘 목록에서 제거한다.
- 나머지 기존 코인설계 스킬과 신규 카테고리 해금 스킬은 유지한다.
- 삭제로 인해 기존 `SkillID` 값이 밀리지 않도록 시장조작 시작 ID를 11로 고정한다.
- 코인설계 아이콘 위 라벨을 다음과 같이 표시한다.
  - 기존 고유 기능
  - 발행량·공급 구조
  - 시장·여론 카테고리 해금
- 아이콘은 `6개 / 2개 / 4개 / 1개` 순으로 배치한다.
- 마지막 `통합운영설계` 1개는 해당 줄의 첫 번째 열에 붙인다.

## 구현 위치

- `SkillPanelUI`가 신규 아이콘을 런타임에 배치하고 라벨을 갱신한다.
- `SampleScene`과 `AndroidSampleScene`에 동일한 DB·UI 참조를 반영한다.
- 삭제된 스킬의 기존 씬 오브젝트는 비활성화해 화면에 표시되지 않도록 한다.

## 검증 기준

- 남은 스킬 에셋 46개, ID 중복 없음
- 두 씬의 스킬 DB 참조 46개
- 두 씬의 직렬화 아이콘 슬롯에서 삭제된 ID 8·9·10 미포함
- 신규 스킬 ID 44~48 유지
