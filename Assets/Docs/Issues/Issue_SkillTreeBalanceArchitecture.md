# 이슈 : 스킬 트리 변경안(v0.5) 구현

기준 문서 : [Notion 스킬 트리 변경안](https://app.notion.com/p/3d794f51302780dbbfe8fc6a676f15e1)

## 범위

- 시장조작 9종, 여론조작 15종, 방어 9종의 비용·효과·최대 구매 횟수 조정
- 기존 코인설계 고유 기능 스킬 8종 유지
- 스테이킹·감사보고서·거버넌스시스템은 코인설계 스킬에서 제거
- 신규 코인설계 세부 카테고리 해금 스킬 5종 추가
- `추가발행권한`의 기존 asset·효과·코인 발행 해금 연동 유지
- 유지 대상 코인설계 asset은 삭제하거나 교체하지 않는다. 제거 대상 3종은 씬 DB와 UI에서도 제외한다.

## 세부 카테고리 해금 규칙

신규 코인설계 해금 스킬은 1회성 구매이며 이전 해금 스킬을 선행조건으로 가진다. 구매가 성공하면
`EventHub.OnSkillTreeChanged`를 통해 연결된 시장·여론 세부 카테고리의 구매 가능 상태를 갱신한다.

| 단계 | 신규 코인설계 스킬 | 비용 | 직접 효과 | 해금 |
| --- | --- | ---: | --- | --- |
| 1 | 토큰기획 | 30,000 | 지지도 +3, 의심도 -1 | 여론조작 > SNS 조작 |
| 2 | 분배구조설계 | 150,000 | 상승률 +4, 거래량 +4 | 시장조작 > 거래량 조작 |
| 3 | 시장진입설계 | 750,000 | 지지도 +3, 상승률 +5 | 시장조작 > 가격 조작 |
| 4 | 신뢰도구축설계 | 3,750,000 | 지지도 +5, 의심도 -3 | 여론조작 > 인플루언서 활용 |
| 5 | 통합운영설계 | 18,750,000 | 지지도 +5, 상승률 +8, 의심도 +3 | 시장조작 > 시장 심리 조작 + 여론조작 > 언론 |

시장·여론의 `SkillSO.unlockGroup`에 연결된 `SkillTreeConfigSO` 선행 스킬을 구매했을 때 해당
세부 카테고리를 구매할 수 있다. 같은 세부 카테고리 안의 시장·여론 스킬끼리는 선행조건이 없고 개별 구매한다.

기존 코인설계 고유 기능 스킬과 방어는 `unlockGroup = None`으로 코인설계 해금 체계와 무관하게 구매한다.

## 코인설계 화면 라벨

코인설계 아이콘 묶음 위 라벨은 단계명이 아니라 현재 배치의 의미를 표시한다.

- 기존 고유 기능
- 발행량·공급 구조
- 시장·여론 카테고리 해금

아이콘 배치는 `기존 고유 기능 6개 / 발행량·공급 구조 2개 / 시장·여론 카테고리 해금 4개 / 통합운영설계 1개` 순서로
내리고, 마지막 1개는 첫 번째 열에 붙인다. 삭제된 스킬이 있던 네 번째 라벨은 비워 UI에서 표시하지 않는다.

## 런타임 구조

- `SkillSO` : 효과, 비용, 명시적 `prerequisites`, 세부 카테고리 `unlockGroup`을 보유한다.
- `SkillTreeConfigSO` : 세부 카테고리와 전용 코인설계 선행 SkillID의 연결을 보유한다.
- `SkillManager` : 카테고리 해금, 선행조건, 구매 횟수, 쿨타임, 잔액, Doubt 안전성을 한 곳에서 판정한다.
- `EventHub` : 구매 성공 후 `OnSkillTreeChanged`를 발행하고 UI가 전체 상태를 다시 계산한다.
- `SkillPanelUI` : 세부 카테고리 잠금 상태와 구매 가능 상태를 표시만 한다.

구매 흐름은 다음과 같다.

```text
아이콘 클릭
  -> EventHub.OnSkillClicked
  -> SkillManager.SelectedSkillId
  -> EventHub.OnSkillPurchased
  -> CanPurchase(unlockGroup/config/prerequisites/구매조건)
  -> 효과 적용 및 구매 성공
  -> OnSkillPurchaseSucceeded + OnSkillTreeChanged + OnMarketUpdated
```

## 밸런스 데이터 적용

시장조작과 여론조작은 Notion 표의 비용·효과·최대 구매 횟수 및 `costMultiplier = 1.4`를 적용했다.
방어는 Notion 표의 비용·효과를 적용하고, 로비만 재사용형 `costMultiplier = 1.4`를 유지했다.
여론조작의 의심도 하락은 기존 `DoubtDecline` 200턴 분할 방식을 유지한다.
